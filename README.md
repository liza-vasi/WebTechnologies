## Описание

HTML/CSS-страница на тему «Историк и реконструктор» с использованием Flexbox и CSS Grid. Включает: имя, аватар, навыки, навигационное меню, карточки исторических эпох, сетку артефактов, боковую панель и форму обратной связи.

## Реализованные элементы
- **Flexbox**: навигационное меню (`.main-nav`), карточки эпох (`.flex-cards`)
- **CSS Grid**: галерея артефактов (`.grid-gallery`) — сетка 2×2
- **Медиа-запросы**: адаптивность для мобильных (<768px) и планшетов (<1024px)
- **Семантические теги**: `<header>`, `<main>`, `<aside>`, `<footer>`, `<section>`, `<article>`, `<nav>`, `<time datetime="...">`
- **CSS-переменные** (`:root`) для единой цветовой схемы
- **Псевдоклассы** ссылок и кнопок: `:hover`, `:visited`, `:active`, `:focus`
- **Контрастность** текста ≥ 4.5:1
- Отсутствие горизонтальной прокрутки (`box-sizing: border-box`)

## Адаптивность
| Устройство | Карточки эпох | Сетка артефактов |
|------------|---------------|------------------|
| Десктоп (>1024px) | 3 колонки | 2 колонки |
| Планшет (768–1023px) | 2 колонки | 2 колонки |
| Мобильный (<768px) | 1 колонка | 1 колонка |
