## Описание

HTML - страница на тему «Историк и реконструктор»: имя, аватар, навыки, проекты, боковая панель и форма обратной связи.

## Структура

- `<header>` — имя и род занятий
- `<main>` — картинка, навыки, проекты, форма
- `<section>` «Навыки» — маркированный список
- `<section>` «Проекты» — нумерованный список
- `<section>` «Связь» — форма обратной связи
- `<aside>` — любимая эпоха
- `<footer>` — копирайт и год
- `<form>` — имя, email, сообщение


## Как открыть

Открыть файл `lab1.html` в любом браузере.

Файл `photo.jpg` должен лежать в той же папке, что и `lab1.html`.
