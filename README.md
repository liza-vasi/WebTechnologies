## Описание

HTML - страница на тему «Историк и реконструктор»: имя, аватар, навыки, проекты, боковая панель и форма обратной связи.

## Реализованные элементы
- Семантические теги: `<header>`, `<main>`, `<aside>`, `<footer>`, `<section>`
- CSS-переменные (`:root`) для единой цветовой схемы
- Псевдоклассы ссылок: `:hover`, `:visited`, `:active`, `:focus`
- Встроенные стили (`style` в `<head>` и в теге `<img>`)
- Ссылки для навигации внутри страницы

## Цветовая схема
| Переменная | Значение | Назначение |
|------------|----------|------------|
| `--color-primary` | `#B85C38` | Акцентный цвет (терракота) |
| `--color-accent` | `#3E2723` | Тёмный фон шапки/подвала |
| `--color-bg` | `#F4E4C1` | Основной фон страницы |
| `--color-text` | `#2E1A14` | Основной цвет текста |
| `--color-light` | `#FFF3E0` | Светлый текст на тёмном фоне |
