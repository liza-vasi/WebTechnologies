## Описание

HTML/CSS-страница на тему «Историк и реконструктор» с добавлением JavaScript для работы с массивом возрастов исторических артефактов.

## Реализованные элементы

- **Массив**: 6 значений возрастов артефактов.
- **prompt**: ввод имени пользователя.
- **alert**: приветствие и вывод среднего возраста и количества древних артефактов.
- **console.log**: вывод результатов вычислений.
- **Функция findMax()**: поиск максимального возраста.
- **Функция filterAncient()**: фильтрация артефактов старше 1000 лет.
- **Функция calculateSum()**: подсчёт суммы возрастов.
- **Цикл for...of**: подсчёт артефактов возрастом до 300 лет.
- **Условие if**: сообщение при наличии артефактов старше 3000 лет.

## Результаты

Программа вычисляет средний возраст артефактов, количество древних и молодых артефактов, долю молодых артефактов и максимальный возраст.
